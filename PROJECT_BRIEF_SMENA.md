# PROJECT BRIEF — «СМЕНА» / MVP «Диспетчер отклонений»

Этот файл кладётся в корень репозитория. Первая команда Claude Code: «Прочитай PROJECT_BRIEF_SMENA.md и выполни Сессию 1».

## Контекст
Обучающий тренажёр для аппаратчиков УПЭ по производственной инструкции № 408-Р-6. Концепция всей системы — Koncepciya_SMENA_408-R-6.md, ТЗ модуля-симулятора насосов — TZ_simulator_pusk_nasosa_408-R-6.md. MVP — карточная игра «Диспетчер отклонений» по Табл. №12 (симптом → причина → действия). Рабочий прототип механики и визуального стиля: dispatcher-otkloneniy-v0.jsx — перенести его логику и стиль «ЦПУ» (тёмный графит, статусные зелёный/янтарный/красный, моно-теги) как есть.

## Стек (обкатанный)
Next.js (App Router) + Prisma + Neon Postgres + Tailwind. Деплой: Vercel с обязательной защитой доступа (см. «Безопасность») или FirstVDS. PWA: manifest + service worker, офлайн-кэш контента.

## Данные
`content/deviations.json` — канонический контент (52 записи, поле `status`). В игру попадают только `status: "ok"`. Каждая запись обязана иметь `page` — кнопка «Сверить с инструкцией, стр. N» в UI. Тексты дословные, редактировать запрещено (только исправление переносов).

## Prisma (набросок)
```prisma
model User      { id String @id @default(cuid()) name String pin String  attempts Attempt[] createdAt DateTime @default(now()) }
model Attempt   { id String @id @default(cuid()) userId String user User @relation(fields:[userId], references:[id]) deviationId Int causeOk Boolean actionOk Boolean createdAt DateTime @default(now()) }
```
Стрики, «освоено», лидерборд — агрегаты по Attempt (mastered = отклонение с ≥1 полностью верной попыткой).

## Сессии Claude Code (одна сессия = одна фича до рабочего состояния)
1. **Каркас.** Next.js + Tailwind + Prisma + Neon, страница `/play`, перенос компонента из dispatcher-otkloneniy-v0.jsx, данные из `content/deviations.json` (фильтр по status). Критерий: игра работает локально.
2. **Профиль.** Вход по имени + PIN (инвайт-список в env), запись Attempt, экран профиля: освоено X/52, лучшая серия, история.
3. **Дополнение контента.** Скрипт `scripts/extract-tabl12.ts`: из локальной копии `408-R-6_AI_READY_superFINAL.md` вытащить полный текст ячеек для карточек №1, 6, 7, 8, 9, 11, 20, 21, 22, 24, 32, 36, 42, 46, 47, 48 (блоки `## Страница 385…398` → `### Full page text`), обновить JSON, `status: "ok"` ставить только после моей ручной сверки (выводить diff на проверку).
4. **PWA + деплой.** Manifest, иконка, офлайн-кэш JSON; деплой с закрытым доступом; лидерборд смены.
5. **TG-бот «Отклонение дня».** Отдельный сервис на FirstVDS (Node + grammY): одна карточка в день из ok-набора, инлайн-кнопки, стрик; общая БД Neon.
6. **Модуль 2.** Глоссарий-спринт (раздел 2 инструкции) тем же карточным движком: `content/glossary.json`.

## Правила
- Никакого выдуманного контента: каждая строка игры имеет `page`-источник.
- Дисклеймер на главной: «Учебный тренажёр. Не заменяет инструкцию 408-Р-6».
- **Безопасность:** документ внутренний. Публичных URL без авторизации не создавать; robots noindex; инвайты только коллегам; в открытых скриншотах контент замазывать.

## Definition of Done для MVP
Коллега открывает ссылку на телефоне, входит по PIN, играет 10 карточек офлайн в перерыв, видит свой прогресс и лидерборд смены.
