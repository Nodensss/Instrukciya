# СМЕНА — тренажёр по инструкции 408-Р-6

MVP «Диспетчер отклонений»: карточная игра «симптом → причина → действия» по Табл. №12 (стр. 385–398). Бриф проекта — [PROJECT_BRIEF_SMENA.md](PROJECT_BRIEF_SMENA.md).

> Учебный тренажёр. Не заменяет инструкцию 408-Р-6. Документ внутренний — публичных URL без авторизации не создавать.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000 — главная со ссылками на модули:
- http://localhost:3000/play — карточная игра «Диспетчер отклонений»;
- http://localhost:3000/sim — 3D-обход установки (пуск насоса). **ДЕМО-режим:** сценарий, оборудование и последовательность операций **выдуманы** для обкатки механики и помечены в интерфейсе, это не материал инструкции 408-Р-6. Реальный порядок пуска подставляется из `TZ_simulator_pusk_nasosa_408-R-6.md`, когда файл появится в репо.

Продакшен-сборка:

```bash
npm run build
npm start
```

БД не нужна: игра читает контент из `content/deviations.json` (в игру попадают только записи со `status: "ok"`). Prisma-схема (`prisma/schema.prisma`) подключается в Сессии 2 (Neon Postgres, профили, попытки).

## Структура

- `content/deviations.json` — канонический контент, 52 записи. Тексты дословные, редактировать запрещено (только исправление переносов); у каждой записи есть `page` — страница-источник.
- `reference/dispatcher-otkloneniy-v0.jsx` — рабочий прототип (источник механики и стиля «ЦПУ»), в сборку не входит.
- `components/DispatcherGame.tsx` — игра, перенесённая из прототипа.
- `app/play/page.tsx` — страница игры: читает JSON, фильтрует `status === "ok"`.
- `components/PumpWalkSim.tsx` — 3D-обход установки на Three.js (пуск насоса), ДЕМО-контент.
- `app/sim/page.tsx` — страница 3D-обхода.
- `prisma/schema.prisma` — набросок схемы для Сессии 2.
